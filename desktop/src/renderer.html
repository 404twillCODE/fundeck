              How to set up external access
              

                
FunDeck uses port 5250 (HTTP/TCP). When creating a tunnel, use TCP port 5250 or HTTP pointing to port 5250.

                
Option 1: ngrok

                
    
                  
  1. Install ngrok: ngrok.com/download
    2. 
                  
  2. Start your FunDeck server in this app (listening on TCP port 5250).
    3. 
                  
  3. In a terminal run: ngrok http 5250 (exposes HTTP over TCP on 5250).
    4. 
                  
  4. Copy the https URL ngrok shows (e.g. https://abc123.ngrok-free.app).
    5. 
                  
  5. Paste it above and click Save. The QR code and copy button will use this URL.
    6. 
                

                
Option 2: playit.gg

                
    
                  
  1. Sign up at playit.gg and install the playit.gg agent.
    2. 
                  
  2. Start your FunDeck server in this app.
    3. 
                  
  3. In the playit.gg agent, add a tunnel: type TCP (or HTTP if available), port 5250, target localhost:5250.
    4. 
                  
  4. Copy the public URL playit.gg gives you, paste it above, and click Save.
    5. 
                

                
Once saved, the Copy external link button appears and the QR code will open this URL so anyone can join from anywhere.
